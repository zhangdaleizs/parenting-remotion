# 高点击率视频封面设计（黑板解题板 · 深色板书风）

为黑板解题板视频设计**吸引点击的封面图**。封面是短视频第一竞争点——用户划到视频先看封面，点击率决定流量。

> 视觉一律用黑板体系：中灰板底 `#3E3F46` + 高对比白/黄橙，**禁止**卡通角色、糖果装饰、白描边标题、浅色糖果渐变底。

## 封面点击率法则

| 法则 | 做法 | 为什么 |
|:----:|------|------|
| **1. 主视觉 = 具象点题** | 画**题目里的具体物件**（蓝莓盒/苹果/水池/车…），其次才是量条/几何；占 40%+ | 纯抽象量条看不出"讲的是啥"；具象物件一眼点题（2026-09-10 买差封面教训） |
| **2. 疑问句标题** | 标题用"共带了多少钱？""几小时追上？" | 疑问句 > 感叹句 |
| **3. 画面只传达一件事** | 一个主视觉 + 一个疑问句 + 一行条件句，不堆副标题 | 用户 0.5s 内要懂视频讲什么 |
| **4. 深底高对比** | 中灰板底 + 白/黄橙大字；标题用黄（最亮） | 深底上高对比最醒目，别用灰字低对比 |
| **5. 颜色 ≤3 种** | 板底 + 图形 1-2 色 + 标题 1 色 | 配色混乱直接拉低点击率 |
| **6. 标题够大** | 横版 ≥150px / 竖版 ≥100px，缩略图仍看得清 | 手机端小图是主战场 |
| **7. 线条统一手绘感** | 量条用 `MeasureBar`（粗线 + 端钩），花括号大而明显 | 与视频内视觉一致，有板书质感 |
| **8. 层次不单调** | 背景径向光 + 淡数学符号水印 + 主视觉投影 | 纯平深灰 + 少量元素会显得单调（2026-09-10 反馈） |

**核心原则**：**图形是视觉，文字是辅助。** 主视觉要**具象点题**——优先画题目里的实物（蓝莓盒/苹果/水池），其次才是抽象量条/几何；标题只抛一个疑问句。

## 设计流程

```
提炼主视觉图形 → 写 CoverScene 组件 → 注册双 Composition → 渲染验证 → 用户确认
```

### Step 1: 提炼主视觉图形（最重要）

把题目**最能说明问题的图形**找出来做主视觉，这是封面的灵魂：

| 题目 | 主视觉图形 |
|------|-----------|
| 买差问题 | **蓝莓盒 ×2 + 虚线空盒**（具象点题），可叠加量条 |
| 和差问题 | 两数上下对齐量条 + 和/差括号 |
| 盈亏问题 | 实物分堆（苹果/饼干）+ 两次分配对比 |
| 鸡兔同笼 | 鸡 + 兔 两组图形 |
| 行程问题 | 两车相向对撞 / 路程带 |
| 几何 | 图形本身 + 辅助线 |

**优先具象**：题目若带实物（蓝莓/苹果/水池/车），就先画实物，再考虑是否需要量条补关系——纯量条太抽象，一眼看不出"讲的是啥"。

主视觉直接是"数学事实本身"，观众一眼看到题目核心。封面是 `durationInFrames=1` 的静态图，**不用动画**，用静态 SVG/React 画。

### 封面版式层次（2026-09-10 定稿）

自上而下五层，主视觉占中部 40%+：

```
眉标黄胶囊      "小学数学 · 买差问题"（黄描边胶囊，字用黄）
疑问句标题      黄色楷体大字 + 黄色下划线
条件句          橙色一行把题目读完（兼填充标题与主视觉间的空白）
主视觉          具象图形（蓝莓盒等），带投影浮起
角标            "小学数学 · 解题思维"（灰，opacity 0.65）
```

配套装饰（克制但有层次，防"太单调"）：
- **背景径向光**：左上微亮 → 边缘暗，不要纯平深色
- **数学符号水印**：`+ × ÷ =` 淡色铺四角，`opacity ≈ 0.055`
- **主视觉投影**：`filter: drop-shadow(...)` 让它浮起来

实物画法要点：`BerryBox` 这类实物要有**识别特征**——蓝莓 = 径向渐变球体（亮蓝→深蓝紫）+ 白色高光 + 顶部 5 瓣花萼；不是简单圆点。

### Step 2: 写组件

复制 `templates/CoverScene.tsx` 到项目 `src/scenes/CoverScene.tsx`：

1. **把题目主视觉加进 `MAIN_VISUALS` 注册表**（defaultProps 传 key，避免 ReactNode 序列化问题）；模板内置 `bar-compare` 量条示例，直接换
2. 传 props：`title`（疑问句）/ `eyebrow`（眉标）/ `banner`（可选）/ `visual` / `vertical`

```tsx
<CoverScene
  title="共带了多少钱？"
  eyebrow="小学数学 · 买差问题"
  visual="bar-compare"
/>
```

组件自动生成：中灰板底 + 黄色疑问句标题（楷体）+ 主视觉插槽 + 眉标 + 角标。

**项目需要已有**：黑板皮肤库 `src/components/`（`MeasureBar` / `BOARD_THEME` / `FONT_HAND` 等，模板 `scene-based-video` 已自带）。

主视觉图形以 **(0,0) 为中心**绘制，CoverScene 用 `translate(宽/2, visualY) scale(scale)` 居中——加新图形时照此约定。

### Step 3: 注册 + 渲染（横 4:3 + 竖 3:4 双封面）

> 封面产出**两张**：**横屏 4:3**（1920×1440）+ **竖屏 3:4**（1080×1440）。CoverScene 用 `useVideoConfig()` 自适应尺寸，单组件双布局，只切 `vertical` prop。

在 `Root.tsx` 注册两个 Composition：

```tsx
<Composition
  id="cover"
  component={CoverScene}
  durationInFrames={1}
  fps={30}
  width={1920} height={1440}   // 横屏 4:3
  defaultProps={{ title, eyebrow, banner, visual }}
/>
<Composition
  id="cover-vertical"
  component={CoverScene}
  durationInFrames={1}
  fps={30}
  width={1080} height={1440}   // 竖屏 3:4
  defaultProps={{ title, eyebrow, banner, visual, vertical: true }}
/>
```

渲染双封面：

```bash
npx remotion still cover out/cover.png \
  --browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
npx remotion still cover-vertical out/cover-vertical.png \
  --browser-executable="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
```

若布局需微调，改 `CoverScene.tsx` 中 `L = vertical ? {...}` 布局对象（各元素的 y 与字号）。

### Step 4: 验证 + 用户确认

渲染后 `open out/cover.png` 和 `open out/cover-vertical.png` 让用户分别查看横/竖封面，确认后用于发布。

## 封面设计检查清单

| # | 检查项 | 达标标准 |
|:-:|:-------|:-------:|
| 1 | **主视觉具象点题** | 画题目里的实物（蓝莓盒/苹果…）或量条，占 40%+；**不能只有抽象量条**——一眼要看出"讲的是啥" |
| 2 | 标题是疑问句 | "共带了多少钱？""怎么算？"，不用感叹句 |
| 3 | 画面只传达一件事 | 文字 ≤ 3 处（标题 + 条件句 + 角标），无冗余副标题 |
| 4 | 颜色 ≤3 种 | 板底 + 图形 1-2 色 + 标题 1 色（只用 `BOARD_THEME` 色板） |
| 5 | 标题可读 | ≥150px（横）/ ≥100px（竖），黄或白高对比，缩略图能看清 |
| 6 | 无卡通元素 | 无角色/粒子/糖果装饰/白描边/浅糖果底 |
| 7 | **层次不单调** | 有背景径向光 + 符号水印 + 主视觉投影，不是纯平深色堆几个元素 |
| 8 | 缩略图测试 | 缩到 160×120（4:3）/ 120×160（3:4）仍能看清标题和主体 |

## A/B 测试（提升点击率的关键手段）

- 同一条视频做 **2-3 版**封面（不同主视觉图形 / 不同疑问句文案），后台看数据定稿
- 黑板体系配色固定，靠**换主视觉图形**和**换疑问句**做多版本，别只出一版
