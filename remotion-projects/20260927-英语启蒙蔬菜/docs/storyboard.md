# 分镜表 · 10秒记住一串单词【蔬菜类】

## 形态判断（第 0 步）

来自参考片实测的**新形态：单词列表高亮型**。

| 判据 | 结论 |
|---|---|
| 画面 | 整屏 **9 行单词卡常驻**，不是一段一景、也不是卡片轮播 |
| 动作 | 念到哪一行，**那一行的底色从米白渐变成亮橙**（15 帧），到下一行开始时硬切回米白 |
| 音频 | 每词念「英文单词 → 中文释义」两遍，9 词 |
| 时长 | 参考片 576×1024 / 30fps / 16.33s |

现有 5 种形态（口诀罗列 / 插画讲解 / 信息图 / 英语绘本卡 / 英语歌谣卡）都套不上，
它是「**静态列表 + 逐行高亮**」，属于新增的第 6 种。已回写 `CLAUDE.md`。

### 与原片的差异化（用户 2026-09-27 要求）

原片是米色底 + 底部虚化食材照，本片改成**薰衣草紫**：

- 背景：`radial-gradient` 中心 `#F0EAF9` → 主色 `#E8E0F4` → 边缘 `#D9CDEC`，
  叠一层 `feTurbulence` 颗粒噪点（opacity 0.16，`mix-blend-mode: overlay`）
- ⚠️ **底部那张暖色虚化照片被去掉了** —— 橙色和紫色是补色，留着会打架
- 第 2 个词由参考片的 `carrot 胡萝卜` 换成 **`broccoli 西兰花`**，避免和原片雷同

## 动画

| 动作 | 做法 |
|---|---|
| 高亮渐入 | 该行音频起点 +6 帧开始，`interpolateColors` 米白→亮橙，15 帧 |
| 高亮退出 | **硬切**回米白（不是反向渐变）—— 参考片实测帧 54 还是橙、帧 55 就是米白 |
| 首行 | 帧 6 才渐入（开场头 6 帧全列表无高亮） |
| 标题 / 列表 | 全程常驻，无入场动画（参考片第 0 帧即在场） |
| BGM | 全程铺满，`flying-squirrel.mp3` 音量 0.08；**不加音效**（参考片几乎无音效） |
