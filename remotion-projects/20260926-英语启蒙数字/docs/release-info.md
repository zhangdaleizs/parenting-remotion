## 差异化（vs 参考）

参考片是**问候语**（13 组社交用语），本篇换成**数字认知**，并沿用本仓的 SVG 卡通场景路线：

1. **主题不同**：问候语 → 数字 1-10（同一套「中文提示 + 英文重复」结构，换内容领域）
2. **零素材成本**：10 个物件全部手写 SVG，统一 180×180 虚拟框 + 同一套画法（扁平、圆润、无描边、左上高光）
3. **画面结构统一**：10 段共用一个参数化组件 `NumberScene.tsx`，只有「物件种类」和「数量」两个变量 ——
   孩子看到的唯一规律就是「数量在递增」
4. **「数数」的动画语言**：物件用 `easeOutBack` 逐个**弹**入（本仓其它形态一律用淡入上浮），
   因为数数的语义就是「一个一个蹦出来」；念第 2、3 遍时已入场的物件一起跳一下
5. **英文行逐词点亮**：未念到 22% 灰、念到变黑并弹一下，把重复节奏可视化

## 本篇踩到的坑（已回写 skill）

**TTS 对「中文提示 + 英文重复」的写法极其敏感，而且失败是静默的**：

| 写法 | 结果 |
|---|---|
| `六是 six，six six six。`（重复部分空格分隔） | ✗ 被念成「六十六」 |
| `六是 six。six，six，six。`（句号分隔） | ✗ 提示里的 six 被吞 |
| **`六是 six，six，six，six。`（全逗号分隔）** | ✅ 正确 |

⚠️ 而且**同一个失败模式换音色也躲不掉**（Tina 老师同样中招）。
⚠️ whisper 判不出这类内容（它会把英文数字识别成中文数字、阿拉伯数字或音译），
**最终只能靠人耳确认** —— 这一步在 skill 里是强制确认点。
