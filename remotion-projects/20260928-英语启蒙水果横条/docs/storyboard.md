## 形态判断（第 0 步）

**单词列表高亮型** —— 整屏 **单列 10 行横条**常驻，念到哪一行那一行底色从近白渐变成橙。
与同主题的 `20260928-英语启蒙水果`（3×4 网格）是**同一支片子的两种排布**，视觉体系相同。

| 判据 | 结论 |
|---|---|
| 画面 | 整屏 10 行词卡常驻，不是一段一景、也不是卡片轮播 |
| 动作 | 念到哪行，**那行底色从近白→橙**（15 帧），到下一行开始时硬切回近白 |
| 与网格篇的关系 | 同词表（去掉梨和猕猴桃）、同音频、同图标，**只换排布** |

## 版式（1080×1920）

基线照搬「单词列表高亮型」样板（`20260927-英语启蒙蔬菜`）。**10 行只比样板的 9 行多一行**，
所以行卡几乎不用压（缩 **0.951**，行高 122 → 116）：

```
y=108   标题「每天30秒打卡亲子英语」黑体 700 / 88px      ← 样板 100px，11 字会超出 1080 宽
y=232   副标题「【水果】」#2B2B2B 600 / 66px

y=360   ┌ 浅紫容器 #DCD0F0 (992×1420, r60) ┐   ← 样板 1336 高，加高 84px
y=384   │  行卡 #FBF8FF (908×116, r40)      │   10 张，步进 139   ← 样板 122 / 146
        │   英文+音标 居中 x=198（相对卡左）  │   英文 57px / 音标 38px / 间距 8
        │   图标 87×87 居中 x=503           │
        │   中文 居中 x=772                  │   57px
y=1751  └ 容器底（1780）┘
```

**与样板的对照**：

| | 样板（9 行） | 本片（10 行） | |
|---|---|---|---|
| 容器 | 992×1336 | 992×**1420** | 加高榨空间 |
| 行卡 | 908×122 | 908×**116** | ×0.951 |
| 行步进 | 146 | **139** | |
| 英文 / 音标 / 中文 | 60 / 40 / 60 | **57 / 38 / 57** | ×0.95 |
| 图标 | 92 | **87** | |
| 行内 x 中心 | 198 / 503 / 772 | **不变** | 卡宽没变 |

⚠️ **只压纵向，不动横向** —— 卡宽仍是 908，行内三者的 x 中心保持原值。
校验：行内「英文 57 + 间距 8 + 音标 38 = 103」< 卡高 116 ✓
