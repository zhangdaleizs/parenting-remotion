## 版式（1080×1920）

基线照搬「单词列表高亮型」样板（`20260927-英语启蒙蔬菜`），**但样板只有 9 行，本片 12 行**，
塞不进原来的容器，所以整体压缩重排（缩放系数 **0.803**）：

```
y=108   标题「每天30秒打卡亲子英语」黑体 700 / 88px      ← 样板 100px，11 字会超出 1080 宽
y=232   副标题「【水果】」#2B2B2B 600 / 66px

y=360   ┌ 浅紫容器 #DCD0F0 (992×1420, r60) ┐   ← 样板 1336 高，加高 84px
y=384   │  行卡 #FBF8FF (908×98, r34)       │   12 张，步进 116   ← 样板 122 / 146
        │   英文+音标 居中 x=198（相对卡左）  │   英文 48px / 音标 32px / 间距 6
        │   图标 76×76 居中 x=503           │
        │   中文 居中 x=772                  │   48px
y=1758  └ 容器底（1780）┘
```

**与样板的对照**（9 行 → 12 行的压缩）：

| | 样板（9 行） | 本片（12 行） | |
|---|---|---|---|
| 容器 | 992×1336 | 992×**1420** | 加高榨空间 |
| 行卡 | 908×122 | 908×**98** | ×0.803 |
| 行步进 | 146 | **116** | |
| 英文 / 音标 / 中文 | 60 / 40 / 60 | **48 / 32 / 48** | ×0.8 |
| 图标 | 92 | **76** | |
| 行内 x 中心 | 198 / 503 / 772 | **不变** | 卡宽没变，横向不用动 |

⚠️ **只压纵向，不动横向** —— 卡宽仍是 908，所以行内三者的 x 中心保持原值。
纵向等比缩 0.803，字号同比例，行内「英文 + 间距 + 音标 = 48+6+32 = 86 < 98」放得下。
