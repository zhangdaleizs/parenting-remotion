# 分镜表 · 每天30秒打卡亲子英语【水果】

## 形态判断（第 0 步）

**单词网格高亮型** —— 与 `20260927-英语启蒙味道` 同形态，沿用其已验证的版式与动画规范
（视觉事实源见 `CLAUDE.md` 的「单词网格高亮型结构」）。

| 判据 | 结论 |
|---|---|
| 画面 | 整屏 **3 列 × 4 行 = 12 张水果卡常驻**，不是一段一景、也不是卡片轮播 |
| 动作 | 念到哪张卡，**那张卡的底色从米白渐变成橙**（15 帧），到下一张开始时硬切回米白 |
| 音频 | 每词念「英文单词 → 中文释义」，12 词 |

**本项目没有另找参考片** —— 形态、版式、动画规则全部沿用味道项目已实测验证的规范，
只换词表、配图和文案。

## 版式（1080×1920，9:16 全屏）

**画布从味道篇的 1080×1440（3:4）改成 9:16 全屏**，网格不能等比放大（宽度被 1080 卡着），
所以**加宽卡片 + 收窄边距 + 拉高行距**重新分配：

```
y=95    标题「每天30秒打卡亲子英语」黑体 700 / 88px
y=210   副标题「【水果】」#2B2B2B 600 / 58px

        3×4 网格（无外层容器，卡直接排在底色上）
y=265   ┌ 310×350 r26 卡 ┐            列 x = 40 / 385 / 730
        │   图 132×132 r18  中心 y=卡顶+76     │            行 y = 265 / 675 / 1085 / 1495
        │   英文 64px Arimo 600  中心 y=卡顶+185 │   ← 长词自动缩字，上限宽 286px
        │   音标 36px Arimo 400  中心 y=卡顶+235 │
        │   中文 50px 苹方 700   中心 y=卡顶+295 │
y=1845  └ 网格底 ┘（下留白 75）
```

**与 3:4 版的对照**（可反推任意画布高度的重排方式）：

| | 3:4（味道篇） | 9:16（本片） | 变化 |
|---|---|---|---|
| 画布 | 1080×1440 | 1080×1920 | 高度 ×1.33 |
| 左右边距 | 114 | **40** | 收窄，给卡片让宽 |
| 卡 | 261×253 | **310×350** | 宽 ×1.19 / 高 ×1.38 |
| 列步进 | 295 | 345 | — |
| 行步进 | 302 | 410 | 拉开，填满多出来的高度 |
| 图 | 104 | 132 | ×1.27 |
| 英文 / 音标 / 中文 | 54 / 30 / 40 | 64 / 36 / 50 | ×1.19 / 1.2 / 1.25 |

⚠️ 宽度方向只能放大 19%（3 列要塞进 1080），高度方向能放大 38% ——
所以**卡片从近正方形（1.03）变成了竖长形（0.886）**，卡内四段的中心距要跟着重排，
不能直接把 3:4 的值乘以一个系数。

## 高亮规则

- 该卡音频起点 **+6 帧**开始，`interpolateColors` 米白→亮橙用 **15 帧**
- 退出是**硬切**回米白，不是反向渐变
- 标题、副标题、12 张卡**全程常驻**，无入场动画
